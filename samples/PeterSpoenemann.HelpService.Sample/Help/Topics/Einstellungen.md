# settings | Einstellungen

## Worum geht es? {#ueberblick}

Auf dieser Registerkarte ändern Sie die **persönlichen Einstellungen** des Samples.
Der Anzeigename wird nur beispielhaft verwendet; das *Farbschema* zeigt eine typische Auswahlliste.

![Schematische Darstellung der beiden Registerkarten](../Images/sample-tabs.svg)

> [!TIP]
> Mit `F1` öffnen Sie jederzeit die Hilfe zur gerade aktiven Registerkarte.

## Felder

| Feld | Bedeutung | Beispiel |
|------|-----------|----------|
| Anzeigename | Name für die Oberfläche | `Beispielbenutzer` |
| Farbschema | Darstellung der Anwendung | Systemeinstellung |

Farbschema
:   Legt fest, ob die Anwendung hell, dunkel oder entsprechend der Windows-Einstellung dargestellt wird.

## Empfohlene Schritte

1. Tragen Sie einen Anzeigenamen ein.
2. Wählen Sie das gewünschte Farbschema.
3. Wechseln Sie zur Registerkarte **Auswertung**.

Weitere Informationen finden Sie unter [Auswertung erstellen](topic:reports).
